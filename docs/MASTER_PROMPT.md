# CleanSpot - Master Project Prompt

You are building CleanSpot. Always read `docs/MASTER_PROMPT.md` before starting a task.

## Development Rules & Guidelines
- **Task Scope**: Work only on the current task.
- **Security & Secrets**: Never put API keys in Flutter code; do not commit secrets.
- **Client Security**: Never award points or approve reports from the client side (backend/cloud functions authority only).
- **Transparency**: List every file you create or change.
- **Verification**: Explain how to test; run tests/analyzers (`flutter analyze`, `flutter test`) before saying you are done.
- **Isolation**: Do not touch unrelated files.
- **Architecture**: Use Riverpod, GoRouter, and a feature-first structure.
